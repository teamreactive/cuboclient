# cuboclient

[![No Maintenance Intended](http://unmaintained.tech/badge.svg)](http://unmaintained.tech/)

:package: The front-end of Cubo, a system for managing an equipment business: clients, suppliers, products, quotes and purchases. Written in AngularJS.

## Usage
If you already have Node.js installed on your machine, install the dependencies and start the development server:
```
npm start
```

Then open [http://localhost:8000/app](http://localhost:8000/app) in your browser.
